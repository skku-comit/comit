# 헤더 및 활동 페이지

## Goal

계정 상태에 맞는 헤더와 공개 세션·프로젝트 목록 및 상세 페이지를 제공한다.

## Context

0007 헤더, 0008 라우팅, 0009 사용자 관리의 기존 디자인과 인증 흐름을 유지한다.

## Scope

### apps/web

헤더·계정 드롭다운, 브라우저 인증 상태, 세션·프로젝트 콘텐츠 및 목록·상세 경로.

## Requirements

- 메뉴를 코밋 소개, 스터디, 세션, 프로젝트, 소식 순서로 제공한다.
- 비로그인 시 부원 가입·로그인, 로그인 시 계정 정보·내 활동·로그아웃을 제공한다.
- 인증 확인 중 로딩, 이름 조회 실패 시 이메일, 환경 미설정 시 비로그인 메뉴를 제공한다.
- 세션·프로젝트는 웹 내부 타입 데이터와 별도 상세 경로를 사용한다.
- 실제 초기 데이터는 비워 두고 준비 중 안내를 제공하며 없는 상세는 404로 처리한다.
- 모바일, 키보드, Escape 및 바깥 클릭 닫힘을 지원한다.

## Constraints

DB·API·관리자·신청·참여·검색·필터·페이지네이션은 추가하지 않는다.

- [x] 계정 상태와 조회 실패·로그아웃을 확인한다.
- [x] 데스크톱·모바일 탐색과 계정 드롭다운 접근성을 확인한다.
- [x] 빈 목록·404 및 테스트 데이터의 목록·상세·선택 정보를 확인한다.
- [x] lint·typecheck·build·포맷 검사를 수행한다.
