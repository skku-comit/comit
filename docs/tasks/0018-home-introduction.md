# 소개 페이지를 메인으로 전환

## Goal

기존 소개 페이지를 코밋의 메인 페이지로 사용한다.

## Context

0017 소개 페이지의 콘텐츠와 디자인을 유지하며 기존 메인 화면을 대체한다.

## Scope

### apps/web

메인·소개 경로와 공통 상단 메뉴.

## Requirements

- 기존 소개 페이지와 스타일을 `/`로 이동하고 기존 메인 콘텐츠를 제거한다.
- 데스크톱과 모바일 상단 메뉴에서 코밋 소개 그룹을 제거한다.
- `/about`은 `/`로 영구 리다이렉트한다.
- 로고의 홈 이동, 활동 링크, 가입 버튼과 계정 메뉴 동작을 유지한다.

## Constraints

소개 페이지의 콘텐츠와 디자인은 유지한다. 가입 안내는 기존 부원 가입 버튼과 메인 가입 링크로 접근한다.

## Acceptance Criteria

- [x] `/`에서 소개 페이지의 모든 섹션을 볼 수 있다.
- [x] `/about`이 메인으로 이동한다.
- [x] 데스크톱·모바일에서 코밋 소개 메뉴가 사라지고 다른 메뉴가 동작한다.
- [x] lint·typecheck·build·포맷 검사를 통과한다.

## Verification

- web lint·typecheck·프로덕션 build 통과.
- 데스크톱 메인 콘텐츠와 코밋 소개 메뉴 제거 확인.
- `/about` 접속 후 `/`로 이동 확인.
- 390px 모바일 메뉴에서 스터디 이동 후 메뉴 닫힘, 로고로 새 메인 복귀 확인.
- 변경 파일 포맷 검사와 diff 공백 검사 통과.
