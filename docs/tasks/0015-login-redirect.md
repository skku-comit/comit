# 인증 필요 기능의 로그인 이동

## Goal

비로그인 상태로 인증이 필요한 기능에 접근하면 오류 대신 로그인 페이지로 이동한다.

## Context

0009 부원 관리와 0011 스터디 관리의 공통 API 요청 함수는 인증 오류를 일반 오류로 표시하고 있었다.

## Scope

### apps/web

공통 API 인증 오류 처리, 스터디 개설 진입 확인, 공개 상세의 선택적 개인 정보 조회.

### apps/admin

공통 API 인증 오류 처리.

## Requirements

- 인증 필요 요청이 401을 반환하면 `/login`으로 이동한다.
- 이동 중 오류 UI와 후속 요청 처리를 실행하지 않는다.
- 스터디 개설은 폼을 표시하기 전에 인증을 확인한다.
- 공개 스터디 목록·상세는 비로그인 열람을 유지한다.
- 권한 부족(403)과 서버 오류는 기존 오류 처리를 유지한다.

## Constraints

API의 인증·인가 검증과 로그인 콜백 경로를 변경하지 않는다.

## Acceptance Criteria

- [x] 웹·관리자 공통 요청의 401 로그인 이동과 오류 UI 억제를 확인한다.
- [x] 공개 상세의 선택적 인증 조회는 자동 이동하지 않는다.
- [x] 스터디 개설 페이지는 진입 시 인증을 확인한다.
- [x] 403·정상 응답 및 lint·typecheck를 검증한다.

## Verification

2026-10-11.

- web/admin lint와 typecheck 통과.
- 두 앱의 실제 API 도우미를 TypeScript 변환 후 모의 응답으로 실행해 401 로그인 이동, 이동 중 Promise 미완료, 선택적 조회의 이동 제외, 403 오류 유지, 200 응답을 확인했다.
- 실제 브라우저 및 학교 Google OAuth 흐름은 재실행하지 않았다.
