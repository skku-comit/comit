# 공개 웹사이트 헤더

## Goal

구름 웹사이트를 참고해 코밋 헤더의 배치와 탐색 경험을 개선한다.

## Context

참고: https://www.goorm.io/. 0006 공개 홈페이지와 공통 디자인 시스템을 유지한다.

## Scope

### apps/web

헤더 컴포넌트 분리, 중앙 메뉴와 설명형 드롭다운, 로그인·가입 안내, 모바일 메뉴.

## Requirements

- 왼쪽 로고, 중앙 탐색 메뉴, 오른쪽 액션을 배치한다.
- 소개·활동 드롭다운은 기존 섹션에 연결한다.
- 키보드 탐색, Escape 닫기와 포커스 복귀, 바깥 클릭 닫기를 지원한다.
- 모바일에서 설명형 탐색과 로그인·가입 안내를 제공한다.

## Constraints

본문 및 인증 기능은 변경하지 않고 기존 토큰과 Button을 재사용한다.

## Acceptance Criteria

- [x] 데스크톱 헤더와 드롭다운을 확인한다.
- [x] 모바일 메뉴와 섹션 이동을 확인한다.
- [x] lint, typecheck, build를 통과한다.

## Verification

- web lint·typecheck·프로덕션 build를 통과했다. 빌드는 샌드박스 포트 제한으로 실패 후 권한 허용으로 재실행했다.
- 브라우저에서 소개·활동 드롭다운, Escape 닫기, 바깥 클릭 닫기, 기존 로그인 안내 연결을 확인했다.
- 390px 모바일에서 메뉴 펼침, 가입 안내 이동 후 닫힘과 가로 넘침 없음을 확인했다.
