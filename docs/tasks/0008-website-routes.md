# 공개 웹사이트 페이지별 라우팅

## Goal

앵커로 이동하는 단일 페이지를 Next.js App Router의 페이지별 경로로 분리한다.

## Context

0006 공개 웹사이트와 0007 헤더의 콘텐츠·디자인·인터랙션을 유지한다. 소개와 활동은 하나의 페이지에 통합한다.

## Scope

### apps/web

홈, 소개·연혁·활동, 스터디, 소식, 가입 안내 페이지와 공통 레이아웃·탐색.

## Requirements

- `/`에는 기존 메인 소개와 그래픽, 소개·가입 안내 이동 버튼을 둔다.
- `/about`에 소개·연혁·주요 활동을 모은다.
- `/studies`에 검색·유형 필터·상세 다이얼로그를 유지한다.
- `/news`에 소식 준비 중 안내, `/join`에 가입·재등록 절차와 FAQ를 둔다.
- 공통 헤더·푸터·본문 바로가기·로그인 안내를 레이아웃에서 제공한다.
- 콘텐츠 이동에는 `next/link`를 사용하고 현재 경로에 `aria-current="page"`를 적용한다.
- 헤더의 활동 메뉴는 제거하고 스터디·소식을 독립 메뉴로 제공한다. 활동 콘텐츠는 소개 페이지에 유지한다.
- 메뉴 선택과 경로 변경 시 메뉴를 닫고 기존 키보드·Escape·바깥 클릭 동작을 유지한다.
- 각 페이지에 주 제목과 개별 메타데이터를 제공한다. 페이지는 서버 컴포넌트를 기본으로 하고 인터랙션만 클라이언트 컴포넌트로 분리한다.

## Constraints

기존 문구·디자인과 준비 중 상태를 유지한다. 인증·API·스터디 상세 라우트와 기존 해시 URL 자동 이전은 추가하지 않는다. 접근성용 `#main` 링크는 유지한다.

## Acceptance Criteria

- [x] 다섯 경로를 직접 열고 새로고침할 수 있다.
- [x] 메뉴·홈 버튼·로고로 페이지를 이동하고 뒤로·앞으로 가기를 사용할 수 있다.
- [x] 스터디 검색·필터·결과 없음·상세 안내와 공통 로그인 안내가 동작한다.
- [x] 모바일 메뉴가 이동 후 닫히며 데스크톱·모바일 탐색이 동작한다.
- [x] lint·typecheck·프로덕션 build·변경 파일 포맷 검사를 통과한다.

## Verification

- web lint·typecheck·프로덕션 build를 통과했고 다섯 경로가 정적 페이지로 생성되었다.
- 내장 브라우저에서 홈 → 소개 → 스터디 → 소식, 로고 홈 이동, 뒤로·앞으로 가기, 직접 접속과 새로고침을 확인했다.
- 자율 스터디 필터, 검색 결과 없음, 상세 안내와 Escape 닫기, 소식 헤더 및 가입 페이지에서 공통 로그인 안내 열기를 확인했다.
- 소개 드롭다운의 현재 페이지 표시, Escape 포커스 복귀와 바깥 클릭 닫기를 확인했다.
- 1440px 데스크톱과 390px 모바일에서 모든 경로의 가로 넘침 없음을 확인했다. 각 페이지의 h1이 하나씩 있는지 확인했고, 모바일 가입 안내 메뉴 이동 후 닫힘을 확인했다.
- Playwright CLI 준비가 지연되어 내장 브라우저로 검증했다. 샌드박스 포트 제한 때문에 빌드는 권한 허용 후 실행했고, 기존 3000 포트가 사용 중이어서 검증 서버는 3100 포트를 사용했다.
