# 코밋 소개 페이지

## Goal

FORIF 소개 페이지의 시각적 흐름을 참고해 코밋 `/about` 페이지를 구성한다.

## Context

- 참고: https://forif.org/club
- 기존 코밋 소개·활동·연혁의 사실 정보와 공통 헤더·푸터를 유지한다.

## Scope

### apps/web

`/about` 페이지와 해당 페이지에 한정한 스타일.

## Requirements

- 큰 타이포그래피의 히어로, 키워드 흐름, 이름 소개, 활동, 연혁, 가입 안내를 구성한다.
- 코밋의 초록색과 기존 콘텐츠를 활용한다.
- 활동은 기존 스터디·세션·프로젝트 경로로 연결한다.
- 모바일과 다크 테마, 키보드 탐색, 모션 감소 설정을 지원한다.

## Constraints

활동 사진이 없어 코드 그래픽을 사용한다. 실제 사진과 미확인 연혁·실적은 추가하지 않는다.

## Acceptance Criteria

- [x] 소개·활동·연혁과 가입 안내가 `/about`에서 표시된다.
- [x] 데스크톱·모바일 레이아웃을 확인한다.
- [x] lint·typecheck·build·변경 파일 포맷 검사를 통과한다.

## Verification

- web lint·typecheck·프로덕션 build와 변경 파일 포맷 검사 통과.
- 1280px 데스크톱과 390px 모바일에서 가로 넘침 없음, h1 하나 확인.
- 모바일 활동 카드와 소개 앵커 이동 확인.
- 빌드는 샌드박스 포트 제한으로 실패한 뒤 권한 허용 환경에서 성공.
- 다크 테마와 모션 감소는 기존 테마 토큰 및 CSS로 대응했으며 별도 시각 검증은 하지 않음.

- 후속 요청에 따라 OUR VALUES 섹션과 관련 데이터·스타일 제거.
- 후속 요청에 따라 COMIT IN NUMBERS 섹션과 관련 스타일 제거. 소개에서 활동으로 바로 연결.
- 소개와 활동 사이에 OUR NAME 섹션 복원. 사용자가 확인한 Code + Summit, commit과 유사한 발음, Co(같이) + Mit의 의미를 소개한다. Mit에 별도 어원은 부여하지 않는다.
