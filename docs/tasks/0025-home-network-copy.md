# 메인 페이지 연결과 네트워크 메시지

## Goal

메인 표어를 ‘점들을 연결하여 더 넓은 네트워크로’로 변경하고, 메인 페이지 전반의 문구를 사람과 지식, 경험의 연결이라는 주제로 맞춘다.

## Context

0018 작업으로 소개 페이지가 메인 페이지가 되었다. 현재 `apps/web/app/page.tsx`의 소개·활동·연혁·가입 안내 문구를 새 표어에 맞게 변경한다.

## Scope

### apps/web

메인 페이지 문구와 검색 설명.

## Requirements

- 상단의 `about_ { CoMit }` 제목과 기존 스타일을 유지하고, 그 아래 소개 섹션 제목에 요청된 표어를 표시한다.
- 소개, 이름 설명, 활동, 연혁 소개, 가입 안내를 연결과 네트워크라는 주제로 다듬는다.
- 표어는 기존 소개 섹션의 반응형 제목 스타일을 사용한다.

## Constraints

기존 섹션 구조, 활동 링크, 동아리 이름의 유래와 연혁의 사실 정보는 유지한다. 다른 페이지와 공통 UI는 변경하지 않는다.

## Acceptance Criteria

- [x] 상단의 `about_ { CoMit }` 제목이 유지되고, 아래 소개 섹션에 ‘점들을 연결하여 더 넓은 네트워크로’가 표시된다.
- [x] 메인 페이지 각 섹션과 검색 설명에 새 메시지가 반영된다.
- [x] 기존 활동 링크와 연혁 정보가 유지된다.
- [x] web lint·typecheck·build와 변경 파일 포맷 검사를 통과한다.

## Verification

- web lint·typecheck·프로덕션 build 통과.
- 변경 파일 Prettier 검사와 diff 공백 검사 통과.
- 기본 샌드박스에서는 Turbopack 내부 포트 사용 제한으로 빌드가 실패했으며, 권한 제한을 해소한 재실행에서 통과했다.
- 실제 브라우저의 데스크톱·모바일 화면은 확인하지 않았다.
