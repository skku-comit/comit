# 디자인 시스템 기반 공개 웹사이트

## Goal

코밋의 정체성과 활동, 가입·재등록 절차를 공개 홈페이지에서 소개한다.

## Context

0004 기획과 0005 디자인 시스템을 따른다. 공통 초록색 토큰, Pretendard, Button·Card·Badge·Input·Dialog를 재사용한다.

## Scope

### apps/web

반응형 단일 페이지 홈, 소개·연혁·활동·스터디 탐색·소식·가입 안내, 검색과 유형 필터, 상세 안내 다이얼로그, 모바일 메뉴, 메타데이터.

## Requirements

- 확정된 소개 자료를 사용한다.
- 스터디 주제 예시와 실제 개설 목록을 구분한다.
- 미확정 모집 일정·회비·계좌·연락처를 만들지 않는다.
- 모바일 메뉴와 키보드 조작, 검색 결과 없음 상태를 제공한다.

## Constraints

실제 OAuth·회원 신청 저장·회비 확인·관리자 기능은 이번 공개 화면 작업에 포함하지 않는다. 준비 중 상태를 명시하고 신청 완료나 로그인 성공을 흉내 내지 않는다. 활동 사진은 제공된 자산이 없어 코드로 만든 그래픽을 사용한다.

## Acceptance Criteria

- [x] 공개 소개와 연혁·활동·가입 절차를 확인할 수 있다.
- [x] 스터디 유형 필터와 검색, 상세 다이얼로그가 동작한다.
- [x] 모바일 메뉴와 섹션 링크가 동작한다.
- [x] lint·typecheck·build를 통과한다.

## Verification

- web lint·typecheck·프로덕션 build 및 변경 파일 포맷 검사를 통과했다.
- Playwright로 자율 유형 필터, 검색 결과 없음, 상세 다이얼로그와 Escape 닫기, 모바일 메뉴의 가입 안내 이동과 메뉴 닫힘을 확인했다.
- 1440px 데스크톱과 390px 모바일 화면을 확인했고 모바일 가로 넘침이 없었다.
- 빌드는 샌드박스의 포트 생성 제한으로 한 번 실패했으며 권한 허용 후 성공했다.
