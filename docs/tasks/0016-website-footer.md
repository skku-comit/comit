# 공개 웹사이트 푸터 정보 확장

## Goal

공개 웹사이트에서 코밋의 SNS, 동아리방 위치와 회장·부회장 정보를 확인할 수 있도록 푸터를 확장한다.

## Context

기존 푸터는 코밋 소개와 저작권 문구만 제공한다. 사용자가 제공한 참고 이미지의 정보 구성을 활용하며 기존 디자인 토큰을 유지한다.

## Scope

### apps/web

공통 SiteShell의 푸터 정보와 반응형 배치.

## Requirements

- 인스타그램: https://www.instagram.com/skku_comit
- 카카오톡 오픈채팅: https://open.kakao.com/o/sgjzGlKi
- 주소: 경기 수원시 장안구 서부로 2066 학생회관 3층 03312
- 회장: 박상혁, 부회장: 음서희. 전화번호와 전화 링크는 표시하지 않는다.
- SNS 링크는 새 탭에서 열고 접근 가능한 이름과 키보드 포커스를 제공한다.
- 상단 정보 영역과 하단 저작권 영역을 구분하고 좁은 화면에서 줄바꿈한다.
- 푸터 내부의 하단 가로 구분선은 표시하지 않는다.
- SNS는 인스타그램 그라데이션과 카카오톡 노란색 원형 아이콘으로 표시하고 주소 앞에 위치 아이콘을 제공한다.
- SNS 원형은 36px, 내부 SVG는 28px로 배치하고 아이콘 사이 간격은 8px로 유지한다.

## Constraints

지도, 미제공 이메일, 이용약관 및 개인정보처리방침은 추가하지 않는다. 참고 이미지의 다른 동아리 정보는 사용하지 않는다.

## Acceptance Criteria

- [x] 공통 푸터에서 제공된 SNS·주소·회장·부회장 정보를 확인할 수 있다.
- [x] SNS URL이 제공된 정보와 일치하고 전화번호와 전화 링크가 없다.
- [x] web lint·typecheck·build 및 변경 파일 포맷 검사를 통과한다.

## Verification

- web lint·typecheck·프로덕션 build와 변경 파일 포맷 검사, git diff --check를 통과했다.
- 빌드는 샌드박스의 로컬 포트 생성 제한으로 실패한 뒤 권한 허용 환경에서 재실행해 통과했다.
- 실제 브라우저에서 반응형 화면과 링크 클릭은 검증하지 않았다.
