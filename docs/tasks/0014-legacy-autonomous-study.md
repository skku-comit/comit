# 기존 자율 스터디 등록과 스터디장 명칭

## Goal

2026년 2학기 의료인공지능 스터디를 신청이 종료된 기존 운영 자료로 등록하고 사용자 표현을 스터디장으로 통일한다.

## Context

0013 실제 스터디 등록과 사용자 제공 사진. 과거 모집 날짜와 스터디장 계정 연결은 확인되지 않았다.

## Scope

DB의 기존 운영 자료 표시, 자율 신청 차단, 실제 데이터 등록, 공개 화면·운영 화면·API 메시지.

## Requirements

- 의료인공지능, 온라인 진행, 정원 5명, 난이도 5/5와 사진의 설명을 저장한다.
- isLegacy를 기존 운영 자료에만 사용하고 신규 신청을 차단한다. 기술상 날짜 자리표시는 공개 화면에 표시하지 않는다.
- 계정이나 참여 기록을 임의 생성하지 않는다. 스터디장의 실명은 저장소에 포함하지 않고 계정은 미연결 상태로 보존한다.
- 정규 모집 종료 표시를 지원하고 대표를 스터디장으로 바꾼다. 내부 representativeId 필드는 유지한다.

## Constraints

기존 회원·학기·신청 기록 보존. 가상 모집 일자·참여 인원은 표시하지 않는다.

## Acceptance Criteria

- [x] 실제 DB·공개 응답 등록 및 신규 신청 차단 확인.
- [x] 정규·자율 모집 종료와 스터디장 표현 확인.
- [x] 관련 lint·typecheck·build·test·포맷 검사.

## Verification

- 기존 Supabase에 isLegacy 컬럼 추가 마이그레이션 적용. 기존 회원·학기·정규 스터디 기록은 유지했다.
- 단일 직렬화 트랜잭션과 감사 기록으로 의료인공지능 스터디(`f6e3c617-f56c-427d-9a4b-fe325b2eb9bb`) 등록. 학교 계정과 기존 참여 인원은 생성하지 않았다.
- 알 수 없는 날짜는 필수 DB 필드의 epoch 자리표시로만 저장하고 기존 운영 자료 화면에서는 숨긴다. 관리자 수정 폼에서도 잘못된 과거 날짜를 보여주지 않는다.
- API 재시작 후 공개 목록 total 6, 의료인공지능 isLegacy true를 확인했다. 일시적인 DB 연결 오류는 재시도 후 정상 응답을 확인했다.
- 실제 브라우저 상세에서 정원 5명·신청 종료 안내와 신청 버튼 없음, 목록 모집 종료 배지를 확인했다.
- 전체 typecheck·lint·format·build 및 diff 검사 통과. API 테스트 5개 통과, 격리 DB를 지정하지 않아 DB 통합 테스트 3개 건너뜀. 미래 모집 날짜를 넣어도 기존 자료 신청이 차단되는 테스트 포함.
