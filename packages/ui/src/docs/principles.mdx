# 코밋 디자인 시스템

함께 배우는 동아리의 친근함을 밝은 표면, 절제된 초록색, 읽기 편한 한글로 표현합니다.
공개 웹과 관리자는 같은 토큰과 컴포넌트를 사용하며 페이지의 밀도만 다르게 구성합니다.

## 타이포와 간격

Pretendard Variable을 사용합니다. 본문은 16px/1.625, 보조 문구는 14px/1.5,
작은 상태 표시는 12px/1.5를 사용합니다. 제목은 20·24·32·40px, 굵기 600을 기준으로 합니다.
본문에 작은 글자를 과도하게 사용하지 않고 긴 제목은 줄바꿈을 허용합니다.

간격은 4px 단위입니다. 관련 요소는 8·12px, 카드 내부는 24px, 섹션은 32·48·64px를 사용합니다.
공개 웹은 최대 너비 1200px과 모바일 16px·데스크톱 32px 좌우 여백을 권장합니다.
관리자는 필드 간 16px, 표 셀 좌우 16px·상하 12px을 기본으로 합니다.

## 형태와 움직임

모서리는 기존 radius 토큰을 사용합니다. 입력·버튼은 md, 카드는 xl을 사용합니다.
그림자는 카드에 xs, 떠 있는 선택 목록에 md, 다이얼로그에 lg를 적용합니다.
전환은 색상·불투명도 중심으로 150ms를 사용하며 움직임 감소 설정을 존중합니다.

## 사용 기준

- 주 행동은 기본 Button, 보조 행동은 outline, 삭제는 destructive를 사용합니다.
- 서버 등 외부 오류는 Field의 `invalid`와 FieldError의 `match={Boolean(error)}`를 함께 설정합니다. 기본 FieldError는 입력 검증 결과에 따라 표시됩니다.
- 입력은 Field 안에 라벨·설명·오류를 함께 배치합니다. placeholder는 라벨을 대체하지 않습니다.
- 성공·주의·정보·오류는 의미 색상과 읽을 수 있는 문구를 함께 표시합니다.
- Table은 표시 전용입니다. 정렬·필터·서버 데이터는 앱에서 처리합니다.
- Skeleton에는 로딩 안내를, 아이콘 전용 버튼에는 접근 가능한 이름을 제공합니다.
- 공개 컴포넌트는 `@comit/ui/components/button`처럼 개별 경로로 가져옵니다.

## 확인 방법

상단 도구에서 light/dark와 모바일/데스크톱을 선택하세요.
Accessibility 패널에서 자동 검사 결과를 확인하고 키보드 조작도 직접 확인합니다.
조합 예제는 가상 데이터만 사용하며 실제 가입·승인 기능이 아닙니다.
